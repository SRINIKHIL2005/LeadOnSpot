# LeadOnSpot — AI-Powered Lead Scoring Agent

An explainable lead scoring system that uses a deterministic weighted algorithm for scores and a free local Ollama model to explain the scoring evidence.

---

## How It Works

The score is **never generated by an LLM**. The algorithm calculates a deterministic weighted score from 6 dimensions. A locally running LLM generates a human-readable explanation from the score breakdown and lead details; it cannot change the score.

### Scoring Dimensions & Weights

| Dimension | Weight | What It Measures |
|---|---|---|
| Job Title | 25% | Decision-maker level (Founder/CEO = 100, Intern = 5) |
| Company Size | 20% | Employee count (mid-market 51–200 scores highest) |
| Industry Fit | 15% | How well the industry aligns with typical buyers |
| Lead Source | 15% | Quality of the acquisition channel (Referral = 100, Outbound = 45) |
| Requirement Clarity | 15% | Specificity and intent keywords in the requirement |
| Contact Completeness | 10% | How many contact fields are filled |

### Classification Thresholds

| Score | Classification |
|---|---|
| 70–100 | Hot |
| 40–69 | Warm |
| 0–39 | Cold |

### Output Fields

- Lead Score (0–100)
- Lead Classification (Hot / Warm / Cold)
- Lead Quality Assessment
- Positive and Negative Scoring Factors
- Scoring Explanation (LLM-generated, grounded in actual data)
- Confidence Level
- Recommended Next Action
- Full score breakdown per dimension

## Setup Instructions

### Prerequisites

- Python 3.10+
- Node.js 18+
- [Ollama for Windows](https://ollama.com/download/windows)
- A few GB of free disk space for the local model download

### 1. Backend Setup

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`
API docs: `http://localhost:8000/docs`

### 2. Frontend Setup

```bash
cd frontend
npm install
npm start
```

The app will open at `http://localhost:3000`

### 3. Install and start the free local model

Install [Ollama for Windows](https://ollama.com/download/windows), then run this in PowerShell:

```powershell
ollama pull llama3.2:3b
```

The model download is about 2 GB. Keep the Ollama app running. If needed, start its local server in another terminal with `ollama serve`. Then start the backend and frontend using the setup steps above. Ollama runs the model on your computer, without cloud credentials or per-request API fees; explanations use your computer's memory and processing power.

The default model is `llama3.2:3b` at `http://localhost:11434`. To use another model you've downloaded, set `OLLAMA_MODEL`; to use a different local Ollama host, set `OLLAMA_BASE_URL`. If Ollama is stopped or the model is missing, the app returns a clear error instead of showing a canned explanation.

## Customizing the Scoring Rules

All scoring rules are in `backend/scorer.py`. The file is designed to be easily edited:

- **Add/change job titles**: Edit `JOB_TITLE_SCORES` dict
- **Change company size ranges**: Edit `COMPANY_SIZE_SCORES` list
- **Add industries**: Edit `INDUSTRY_SCORES` dict
- **Change weights**: Edit `WEIGHTS` dict (must sum to 1.0)
- **Change Hot/Warm thresholds**: Edit `HOT_THRESHOLD` and `WARM_THRESHOLD`

## Running Tests

```bash
cd backend
python -m unittest -v test_scorer
```

Use `python -m pip install -r requirements.txt` to install the backend and API-test dependencies. The discoverable tests cover score classifications, consistency, name validation, Ollama request construction, and missing/unavailable local model handling. Automated tests mock the Ollama HTTP response; real explanations require the locally installed Ollama service and model.

## API Reference

### POST /score

**Request body:**
```json
{
  "name": "Rahul Sharma",
  "company_name": "ABC Technologies",
  "website": "www.abctechnologies.com",
  "job_title": "Founder",
  "industry": "IT Services",
  "company_location": "Bangalore",
  "company_size": "50-100",
  "lead_source": "Website",
  "requirement": "Looking for CRM software",
  "email": "rahul@example.com",
  "phone": "+91 9876543210"
}
```

**Response:**
```json
{
  "lead_name": "Rahul Sharma",
  "company": "ABC Technologies",
  "score": 93.8,
  "classification": "Hot",
  "confidence": 100,
  "quality_assessment": "Excellent — High-value lead with strong buying signals",
  "explanation": "...",
  "explanation_provider": "Ollama (local)",
  "explanation_model": "llama3.2:3b",
  "positive_factors": ["..."],
  "negative_factors": [],
  "next_action": "Assign to senior sales rep immediately...",
  "score_breakdown": { ... }
}
```

Individual fields are optional, but at least two non-empty fields are required. If a name is provided, both the browser and API require a human name containing letters; names such as `00-10` are rejected. Other lead fields remain free text. Unknown job titles, industries, lead sources, and company-size formats are scored using neutral/default values rather than rejected.

The React form sends the lead fields as JSON to `POST /score` on the FastAPI backend. The backend calculates the weighted score in `backend/scorer.py`; Ollama generates the explanation using the dimension scores, weights, strengths, weaknesses, and relevant lead details. The LLM cannot change the deterministic score. The “Load Sample Lead” button only fills the form as a demo convenience; normal submissions use the values the user entered.

## Tech Stack

- **Backend**: Python, FastAPI, Pydantic
- **AI/LLM**: Ollama with Llama 3.2 3B (local, no API key) — explanations only
- **Frontend**: React, plain CSS
- **Scoring**: Pure rule-based weighted algorithm (deterministic, no randomness)
