# LeadOnSpot — AI-Powered Lead Scoring Agent

An explainable, rule-based lead scoring system that evaluates sales leads using a transparent weighted algorithm and uses AWS Bedrock (Claude) to generate human-readable explanations.

---

## How It Works

The score is **never randomly generated by an LLM**. The algorithm calculates a deterministic weighted score from 6 dimensions. The LLM (Claude via AWS Bedrock) is only used to write a natural-language explanation of the score.

### Scoring Dimensions & Weights

| Dimension | Weight | What It Measures |
|---|---|---|
| Job Title | 25% | Decision-maker level (Founder/CEO = 100, Intern = 5) |
| Company Size | 20% | Employee count (mid-market 51–200 scores highest) |
| Industry Fit | 15% | How well the industry aligns with typical buyers |
| Lead Source | 15% | Quality of the acquisition channel (Referral = 100, Outbound = 45) |
| Requirement Clarity | 15% | Specificity and intent keywords in the requirement |
| Contact Completeness | 10% | How many contact fields are filled |

### Classification Thresholds

| Score | Classification |
|---|---|
| 70–100 | Hot |
| 40–69 | Warm |
| 0–39 | Cold |

### Output Fields

- Lead Score (0–100)
- Lead Classification (Hot / Warm / Cold)
- Lead Quality Assessment
- Positive and Negative Scoring Factors
- Scoring Explanation (LLM-generated, grounded in actual data)
- Confidence Level
- Recommended Next Action
- Full score breakdown per dimension

## Setup Instructions

### Prerequisites

- Python 3.10+
- Node.js 18+
- AWS account with Bedrock access (Claude 3 Haiku enabled in us-east-1)
- AWS credentials configured (`aws configure` or environment variables)

### 1. Backend Setup

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`
API docs: `http://localhost:8000/docs`

### 2. Frontend Setup

```bash
cd frontend
npm install
npm start
```

The app will open at `http://localhost:3000`

### 3. AWS Bedrock Setup

Make sure your AWS credentials have permission to call Bedrock:

```bash
aws configure
# Enter your AWS Access Key ID, Secret, and region: us-east-1
```

Enable the **Claude 3 Haiku** model in AWS Bedrock console → Model access → Request access.

> **Note:** If Bedrock is unavailable or not configured, the system automatically falls back to a rule-based explanation. The score is never affected.

## Customizing the Scoring Rules

All scoring rules are in `backend/scorer.py`. The file is designed to be easily edited:

- **Add/change job titles**: Edit `JOB_TITLE_SCORES` dict
- **Change company size ranges**: Edit `COMPANY_SIZE_SCORES` list
- **Add industries**: Edit `INDUSTRY_SCORES` dict
- **Change weights**: Edit `WEIGHTS` dict (must sum to 1.0)
- **Change Hot/Warm thresholds**: Edit `HOT_THRESHOLD` and `WARM_THRESHOLD`

## API Reference

### POST /score

**Request body:**
```json
{
  "name": "Rahul Sharma",
  "company_name": "ABC Technologies",
  "website": "www.abctechnologies.com",
  "job_title": "Founder",
  "industry": "IT Services",
  "company_location": "Bangalore",
  "company_size": "50-100",
  "lead_source": "Website",
  "requirement": "Looking for CRM software",
  "email": "rahul@example.com",
  "phone": "+91 9876543210"
}
```

**Response:**
```json
{
  "lead_name": "Rahul Sharma",
  "company": "ABC Technologies",
  "score": 93.8,
  "classification": "Hot",
  "confidence": 100,
  "quality_assessment": "Excellent — High-value lead with strong buying signals",
  "explanation": "...",
  "positive_factors": ["..."],
  "negative_factors": [],
  "next_action": "Assign to senior sales rep immediately...",
  "score_breakdown": { ... }
}
```

Individual fields are optional, but at least two non-empty fields are required to score a lead. The browser checks email format when an email is entered; other fields remain free text. Unknown job titles, industries, lead sources, and company-size formats are scored using neutral/default values rather than rejected.

The React form sends the lead fields as JSON to `POST /score` on the FastAPI backend. The backend calculates the weighted score in `backend/scorer.py`; AWS Bedrock is used only to generate the explanation, and the explainer falls back to a rule-based explanation when Bedrock is unavailable.
